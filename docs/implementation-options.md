# Варианты реализации: корпоративный Telegram-бот с базой знаний

> Зафиксировано: 2026-06-26  
> Контекст: заказчик хочет, чтобы сотрудники компании задавали вопросы агенту по документам компании через Telegram. Бюджет ориентир: $20–100/мес. Заказчик согласился на **API** или **AutoClaw**.

---

## Задача заказчика

- Сотрудники пишут в Telegram → получают ответы по базе знаний компании (регламенты, FAQ, инструкции).
- Одна «подписка» / один бот на всю компанию.
- Желательно недорого ($20–100/мес).

**Важно:** одна подписка за $20 на всех без лимитов — нереалистична при активном использовании. Реальный диапазон при 10–20 людях: **$50–100/мес** (хостинг + API).

---

## Вариант 1: Свой Telegram-бот + API

### Схема

```
Сотрудник → Telegram → ваш сервер → RAG (поиск по документам) → LLM API → ответ + источник
```

### Стек (минимальный)

| Компонент | Варианты |
|---|---|
| Telegram | `python-telegram-bot`, aiogram |
| RAG | Chroma, Supabase pgvector, Pinecone |
| LLM API | OpenRouter, OpenAI, Anthropic (дешёвые модели: gpt-4o-mini, claude-haiku) |
| Хостинг | Railway, Render, VPS ($10–20/мес) |

### Плюсы

- Полный контроль: лимиты, whitelist сотрудников, логи, админка
- Предсказуемая поддержка — свой код, своя архитектура
- Легко масштабировать и дорабатывать (Notion, Google Drive, веб-панель)
- Прозрачный счёт за API
- Логично развивать в репозитории `Company-cloude-chat`

### Минусы

- Дольше до первого результата: **1–3 недели**
- Разработка и поддержка на исполнителе

### Бюджет (ориентир)

| Статья | Цена |
|---|---|
| Хостинг | $10–20/мес |
| Vector DB | $0–70/мес |
| API | $20–100/мес (зависит от нагрузки) |
| **Итого** | **$50–100/мес** при умеренной нагрузке |

## Вариант 2: AutoClaw / OpenClaw

### Что это

| Название | Суть |
|---|---|
| **OpenClaw** | Open-source AI-ассистент: Telegram, WhatsApp, Slack + встроенная база знаний (RAG) |
| **AutoClaw** (autoclaw.dev) | Managed-деплой OpenClaw в облако без DevOps |
| **autoclaw.sh** | Гайды и примеры деплоя (не продукт) |
| **TeleClaw** | Готовый Telegram-бот (~$19/мес на **одного** пользователя, не на компанию) |

### Схема

```
Сотрудник → Telegram → OpenClaw (бот) → папка knowledge/ → LLM (BYO API key) → ответ
```

### Плюсы

- Быстрый старт: **2–5 дней**
- Telegram и RAG из коробки
- Один бот в корпоративной группе — все пользуются
- Можно ограничить доступ списком Telegram ID
- AutoClaw снимает боль с сервером и настройкой

### Минусы

- Изначально «личный ассistent», не корпоративный SaaS
- Нет нормальной админки, per-user аналитики из коробки
- Зависимость от молодой экосистемы (OpenClaw, AutoClaw, security-патчи)
- API-ключ всё равно нужен (BYO) — подписка AutoClaw ≠ оплата AI
- Сложнее кастомизировать под специфику заказчика

### Бюджет (ориентир)

| Статья | Цена |
|---|---|
| AutoClaw / хостинг | $5–50/мес |
| API (BYO key) | $20–100+/мес |
| **Итого** | **$50–120/мес** |

## Сравнение

| Критерий | Свой бот + API | AutoClaw / OpenClaw |
|---|---|---|
| Срок до первого результата | 1–3 недели | 2–5 дней |
| Удобство для заказчика | Норм | Очень удобно на старте |
| Контроль | Высокий | Средний |
| Поддержка через полгода | Проще | Зависимость от платформы |
| Лимиты, доступ, админка | Легко добавить | Сложнее |
| Масштаб 20+ человек | Ок | Ок с оговорками |

## Рекомендация (зафиксированная)

### Двухэтапный путь (оптимальный)

1. **Пилот на AutoClaw** (1–2 недели): Telegram + 20–30 документов + 5 тестеров.
2. **Если зашло — перенос на свой бот + API** (2–3 недели): тот же Telegram, та же база, но свой код.

### Если один этап

- **«Нужно через неделю»** → AutoClaw (пилот)
- **«Делаем нормально сразу»** → свой бот + API, без AutoClaw

### Одной фразой для заказчика

> AutoClaw — быстрый старт за неделю. Свой бот на API — чуть дольше, но надёжнее, дешевле в долгую и проще масштабировать. Предлагаю пилот на AutoClaw; если понравится — делаем постоянное решение на API.

---

## Вопросы заказчику (уточнить перед стартом)

1. Сколько сотрудников будут пользоваться?
2. Сколько вопросов в день на человека?
3. Какие документы в базе? (PDF, Notion, Google Drive?)
4. Можно ли отправлять текст в облачный API (OpenAI/Claude)?
5. Обязателен ли Telegram или подойдут Slack / Teams / веб?
6. $20–100 — на всех или на человека?
7. Готовы ли к лимитам (например, 20 вопросов/день на сотрудника)?
8. Кто будет обновлять базу при смене регламентов?

## Пакеты для предложения клиенту

| Пакет | Для кого | Бюджет | Суть |
|---|---|---|---|
| **Старт** | до 10 человек | $50–80/мес | Telegram + дешёвая модель + лимиты |
| **Стандарт** | 10–30 человек | $100–250/мес | Бот + RAG + нормальная модель |
| **Корпоратив** | 30+ / строгая безопасность | $300+/мес | Team-подписки или self-host |

---

## Что нельзя обещать

- «Один ChatGPT Plus на всю компанию через бота» — нарушение ToS
- «$20/мес на 50 человек без лимитов» — математика не сходится
- «Подписка Telegram покроет AI» — Telegram не продаёт LLM
- «Cloud Code заменит API» — если это Cursor/Claude Code, это инструмент для разработки, не корпоративный чат
