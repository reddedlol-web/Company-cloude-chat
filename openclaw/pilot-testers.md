# Список Telegram ID для пилота (5 тестеров + админ)

Telegram user ID — число, не @username. Узнать можно:
- написать боту @userinfobot в Telegram, или
- посмотреть в логах OpenClaw после первого сообщения.

Заполни и перенеси ID в `openclaw.json` → `channels.telegram.allowFrom` и в `groups.*.allowFrom`.
