# База знаний компании

Сюда кладут **только утверждённые** документы для пилота.

## Структура

| Папка | Содержимое |
|-------|------------|
| `faq/` | Частые вопросы |
| `policies/` | Регламенты, политики |
| `onboarding/` | Онбординг новых сотрудников |

## Форматы

- `.md` — предпочтительно (легко править)
- `.txt`, `.pdf` — тоже поддерживаются OpenClaw

## Пилот

На старте достаточно **20–30 документов** и **5 тестеров** (см. `docs/pilot-openclaw-setup.md`).

## Обновление

1. Положи новый/обновлённый файл в нужную папку.
2. Перезапусти gateway или выполни reindex (если доступно в вашем деплое).
3. Проверь одним тестовым вопросом.

**Не клади сюда:** черновики, личные заметки, устаревшие версии регламентов.

> Для основного бота в репозитории (`Company-cloude-chat`) выгрузка из Boss Free идёт в `knowledge/bossfree/` через `python -m src.cli knowledge sync-bossfree` — это отдельный пайплайн, не путать с этой OpenClaw-папкой.
